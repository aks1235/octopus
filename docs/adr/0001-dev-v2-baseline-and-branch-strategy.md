# ADR-0001: dev-v2 基线与分支策略

- 状态: 已接受(2026-09-08)
- 关联: ADR-0007(执行节奏)

## 背景

dev 分支基点是上游 2026-04-09 的 `9851442`,已落后上游 68 commits。上游 v0.11.0 完成故障转移大重构,v0.12/v0.13 完成渠道模型拆表,补丁潮至 v0.13.2(`27aa40d`,2026-09-02)基本收敛。2026-08-24 曾尝试路线 A 迁移(feat/my-features,v1.1.0)因基点失效回滚。

## 决策

- 新建 `dev-v2` 分支,基线钉死 `upstream/master@27aa40d`(v0.13.2),重做期间不追上游新提交
- `dev` 冻结:不再叠功能,仅保留 v1.0.x 紧急热修通道(v1.0.7+ 版本号空间留给它)
- `feat/my-features` 保留不删,仅作移植对照参考

## 后果

- dev-v2 与上游重新对齐后,后续升级回到正常 merge/rebase 轨道
- 冻结 dev 期间生产线逃生通道完整(镜像钉 v1.0.4 可随时回)
- 基线钉死意味着重做期间上游新修复不自动获得,切换后再评估跟进
