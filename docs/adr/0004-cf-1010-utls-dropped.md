# ADR-0004: CF 1010 / uTLS 不带入

- 状态: 已接受(2026-09-08)

## 背景

`ea68f69`(2026-09-04)为绕过 Cloudflare 1010 加入 uTLS 浏览器指纹(566 行,含测试),同日被 `9de1126` 整体回滚。

复盘结论:1010 的根因是用户自己的 Python 脚本调用模型时未携带 User-Agent;客户端补 UA 后问题消失,与 uTLS 无关。

## 决策

- dev-v2 不带 uTLS 功能(渠道表 `utls` 列等残留一并忽略)
- `ea68f69` 留在历史中作参考,不重套

## 后果

- 少一块与上游 client 层的永久冲突面
- 若未来上游真的按 TLS 指纹拦截,届时再评估(可先试上游新加的 `ChannelProxy` 渠道专用代理字段)
