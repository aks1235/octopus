# ADR-0006: dev-v2 首发版本号 v2.0.0

- 状态: 已接受(2026-09-08)

## 背景

镜像 `raynmy/octopus` 现至 `v1.0.6`。v1.1.0 已被 2026-08 废弃的路线 A 线占用(Docker Hub 上有该时代镜像)。dev 冻结后仍可能发 v1.0.7 热修复。本次为数据模型级破坏性切换。

## 决策

dev-v2 首发版本号定为 **v2.0.0**,后续 v2.0.x 迭代。

## 后果

- 主版本号明确表达破坏性,与冻结 dev 的 v1.0.x 版本空间彻底隔离
- 不重用 v1.1.0,避免同 tag 不同内容
- CI 发版流程不变(tag push → aks-fork → 自动镜像/Release)
