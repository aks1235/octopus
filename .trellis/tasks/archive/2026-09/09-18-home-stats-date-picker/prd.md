# 首页统计日期化:趋势任意天 / 热力图导航 / 排名按天

## Goal

把「日期」变成首页统计的一等公民:趋势图可看任意(保留期内的)天,年历热力图从纯展示升级为**日期导航器**(点击格子全页切换),渠道/模型排名支持按选中日查看并保留累计视角。解决用户三连反馈:趋势只能看今天、热力图"指它才能看细节"不直观、排名只有累计不统一。

## Background(2026-09-18 用户反馈,已核实代码)

- `stats_hourlies` 是 24 格环形缓冲:`Hour` 为主键每日覆盖写,内存 `statsHourlyCache [24]` 同构——昨天的曲线**结构性丢失**,非显示问题。
- 渠道/模型排名来自渠道/模型表上的**累计计数**(`ChannelStats`/`ChannelModelStats`),不存在按天维度。
- `relay_logs` 行内已冗余 `channel_id/channel_name/request_model_name` 与 token/cost,按天聚合排名可直接 GROUP BY,默认保留 7 天(`relay_log_keep_period` 可调)。
- 热力图 `activity.tsx` 由 `stats_dailies`(每天一行总量)驱动,54 周年历,悬浮 tooltip,点击无行为。

## Requirements

### R1 热力图 = 日期导航器

- 热力图格子**可点击**(≤今天的日子),点击后整页(趋势/排名/汇总)切换到该日;选中格子高亮描边。
- 页头显示当前查看日期;非今天时提供「回到今天」入口。

### R2 趋势图按选中日渲染

- 后端 `stats_hourlies` 从 24 格环形改为 **(date, hour) 复合主键**按日期留存;内存缓存同步改为按 (date, hour) 组织。
- 小时接口支持 `date` 参数(默认今天),前端趋势图按选中日渲染该日 0-24 点曲线;选中日无数据显示空态。
- **保留期跟随日志**:`relay_log_keep_period`(默认 7 天)超期的小时行由周期任务清理(挂在既有日志清理任务旁)。升级前的历史小时数据不可找回,自升级起积累。

### R3 排名按天 + 累计双视角

- 排名区加「按天 / 累计」切换(或随选中日自动按天+可切累计,进 design 定)。
- 按天:新后端端点,按选中日从 `relay_logs` GROUP BY 聚合渠道排名与模型排名(请求数/token/费用),超出日志保留期的日期返回空并提示。
- 累计:沿用现有累计接口,行为不变。

### R4 兼容

- 现有 `stats_dailies`(热力图数据)、`stats_totals`、日志页等不受影响;迁移 013 保留现有小时行(并入其 `date` 字段值)。
- i18n 三语;实时刷新语义:今天 = 随统计落盘节奏更新,历史天 = 静态快照。

## Non-goals

- 不做小时级渠道/模型下钻(只做日级聚合)。
- 不改日志保留策略本身(小时数据只是跟随它的保留期)。
- 不做自定义日期范围区间(单日选择即可)。

## Acceptance Criteria

- [ ] AC1 热力图点击任意历史天,全页切到该日,选中格子高亮;「回到今天」一键返回
- [ ] AC2 趋势图按选中日渲染;升级后产生的跨天数据(昨天/前天)曲线可查;选中无数据日显示空态
- [ ] AC3 排名按选中日聚合(渠道/模型各一),与趋势同日;累计 Tab 行为与现状一致
- [ ] AC4 超过日志保留期的小时行与按天排名返回空态且有明确提示
- [ ] AC5 迁移后现有 stats_hourlies 数据保留(并入原 date);stats_dailies/日志页零回归
- [ ] AC6 i18n 三语;octopus-verify 自动关卡 + UI 人审(点昨天看曲线/排名、回今天、跨天积累)

## Notes

- 小时数据保留期跟随后,用户把 `relay_log_keep_period` 调大即可看更久,无独立旋钮。
- 本任务在 v2.1.1 发版后实施(工作区保持干净待发版)。
