# 健康检查模型对账:探测结果自动落库

## Goal

健康检查每轮探测时**已经拉到上游模型列表,却直接丢弃**(`internal/task/health.go:52` 只取 bool)。本任务把这份现成的列表按用户已确认的对账语义(43d6cae)落库,实现**定时自动对账**:上游已下线的模型最多存活一个健康检查周期(默认 30 分钟),不再依赖人工去渠道页点探测。

## Background(已核实)

- **手动对账已存在**:渠道编辑器的探测按钮(`web/src/components/modules/channel/probe.ts`)在 2026-09-18 由用户定为**替换语义**:探测结果替换该凭据名下的模型与授权,上游没有了的不再保留;"分组成员随授权级联消失属预期(用户确认)"(commit 43d6cae)。
- **自动路径只判活不对账**:定时健康检查(`health_check_interval`,默认 30 分钟,0 关闭)调 `probe.FetchModels`,任一凭据任一侧 2xx 即判健康,**拉到的模型清单被丢弃**;失败计数达阈值(默认 3)自动禁用渠道。
- **9-24 用户实测**:某渠道一直显示上游已下线的模型,直到手动同步才消失——因为没有定时任务对账。
- **跳过健康检查的渠道**(如天翼云,`health_check_skip=1`)不参与探测,本任务不覆盖(见 Non-goals)。
- 渠道保存路径已有完整骨架可复用:`op.ChannelUpdate` → `syncChannelChildren`(事务内整体替换凭据/模型/授权)→ `GroupRegexSync` + `GroupManualAbsorb`(`internal/op/channel.go:128,200-204,277`)。

## Requirements

- **R1 探测返回清单**:`probe.FetchModels` 改造(或新增并行入口)返回**逐凭据、逐侧**(OpenAI / Anthropic)的模型清单与协议位,不再只返回 bool;判活语义不变(任一凭据任一侧 2xx 即健康)。
- **R2 逐凭据对账**:健康检查对候选渠道的**每个启用凭据**两侧都探测;探测成功的凭据按 43d6cae 语义对账——本轮结果**替换**该凭据名下的模型与授权(按名匹配保留主键与统计),新模型加入并携带协议位;探测失败的凭据**不对账**(不确定就不动)。
- **R3 过滤口径**:对账结果过全局黑名单 + 渠道白名单,与手动探测、后端拉取同语义(`modelNameKept`)。
- **R4 防误删护栏**:
  - 任一凭据本轮探测失败(非 2xx / 解析失败)→ 该凭据跳过对账,健康判定照旧;
  - 探测成功但结果为空列表 → 该凭据跳过对账(空列表更可能是上游故障而非全部下架);
  - 渠道级整轮超时 → 该渠道不落任何对账结论。
- **R5 级联与重算**:授权增删级联分组成员(预期);对账落库后走渠道保存同款的 `GroupRegexSync` + `GroupManualAbsorb` 与分组变更事件,前端即时看到成员变化。
- **R6 统计保留**:保留下来的模型/授权沿用既有主键与统计(与手动保存路径同口径)。
- **R7 兼容**:不新增独立设置项,对账跟随健康检查(`health_check_interval=0` 即两者全关);手动探测行为不变;渠道编辑保存路径行为不变。

## Non-goals

- **跳过健康检查的渠道**不做对账(它们不探测;给它们做定时对账等于变相强制探测,语义冲突)。
- 不做对账独立开关、不调健康检查默认间隔。
- 不动价格同步(24h `model_info_update_interval`,那是 models.dev 价格,另一回事)。
- 不做"删除量熔断"(如删除超 X% 跳过)——R4 的逐凭据护栏已覆盖主风险,先不过度设计。

## Acceptance Criteria

- [ ] AC1 上游下线某模型后,最多一个健康检查周期内该模型自动从渠道消失(授权、分组成员随之级联),无需人工干预。
- [ ] AC2 上游新增模型后,下一轮自动出现且协议位正确。
- [ ] AC3 上游 5xx / 返回空列表时**不误删**(该凭据本轮不对账),渠道健康状态照旧判定。
- [ ] AC4 探测失败的凭据名下模型原样保留。
- [ ] AC5 手动探测、渠道编辑保存行为不变(回归)。
- [ ] AC6 对账后分组成员变化的前端可见性与渠道保存路径同款(实现期核实:渠道触发的成员变化今天本就不发分组 SSE 事件,属既有边界,前端经拉取路径看到;事件化留待后续任务)。
- [ ] AC7 `go test ./internal/...` 全绿;octopus-verify 全流程通过并写 marker。
